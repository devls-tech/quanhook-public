# quanhook-public

Public-facing resources for quanhook (privacy policy, support page) while the main [quanhook.com](https://quanhook.com) site is under construction.

Published via GitHub Pages:

- Landing: https://devls-tech.github.io/quanhook-public/
- Privacy: https://devls-tech.github.io/quanhook-public/privacy
- Support: https://devls-tech.github.io/quanhook-public/support

## Enabling GitHub Pages

In the repo on GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / root**. Save. Pages are live a minute later.

## Editing

Pages are plain Markdown. Edit `index.md`, `privacy.md`, or `support.md` and push to `main` — GitHub Pages rebuilds automatically.

When you update the privacy policy, bump the `_Last updated:_` date at the top of `privacy.md`.
